# Домашнее задание 1, задания 1–3

| Файл | Что внутри |
|------|------------|
| `task1.ipynb` | **Задание 1.** Анализ активаций и градиентов по слоям для 3 функций активации (ReLU, tanh, identity) × 6 способов инициализации (нулевая, константная, две случайные, Xavier, Kaiming); сравнение сходимости на FashionMNIST с SGD (4 активации × 4 инициализации). Четвёртая активация — LeakyReLU. |
| `task2.ipynb` | **Задание 2.** Мини-autograd: класс `Node` со сложением, умножением и ReLU, обратный проход с топологической сортировкой. 19 тестов на `unittest`, включая численную проверку градиентов методом конечных разностей. |
| `task3.ipynb` | **Задание 3.** Свои оптимизаторы: **AdamW** (основной), а также **Momentum**, **Nesterov**, **Adagrad**. Описания идей алгоритмов, 14 тестов (сравнение с `torch.optim` + аналитические проверки) и сходимость на FashionMNIST: ошибка, норма градиентов, распределения весов. |

## Как запускать

* Python с `torch`, `torchvision`, `matplotlib`, `pandas` (см. `requirements.txt` в корне репозитория).
* Датасет FashionMNIST скачивается автоматически в `<корень репозитория>/data` при первом запуске.
* Ноутбуки самодостаточны: каждый можно открыть и выполнить сверху вниз.
